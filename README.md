# Formalizing the Character Table of S₃ in Lean 4

This project explores the formalization of elementary representation
theory in Lean 4, with the goal of constructing and verifying the
character table of the symmetric group S₃.

## Goals

- Work with representations of finite groups in Lean.
- Define and compute characters.
- Study the conjugacy classes of S₃.
- Construct the character table of S₃.
- Formally verify character orthogonality.

## Motivation

I am learning Lean 4 and exploring how formalization can be used
to connect mathematical research in representation theory with
computer-verified mathematics.
